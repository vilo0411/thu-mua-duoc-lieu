# Anchor Index — theo dõi anchor text nội bộ

Sổ ghi chép **append-only** để tuân thủ PRD §8.3 Rule 6 (không dùng cùng 1 anchor text cho cùng 1 URL đích). Không phải nguồn dữ liệu đầy đủ (không audit lại toàn bộ site ngay lập tức) — chỉ ghi lại các link được thêm/sửa qua `/link`, `/drafting`, `/seo-optimize` để lần sau có căn cứ tránh lặp.

## Format

```
- /duong-dan-dich ← "anchor text đã dùng" (nguồn: slug-bai-viet, ngày)
```
